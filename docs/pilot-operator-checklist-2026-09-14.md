# 墨题 7 天有偿内测运营记录模板（2026-09-14）

本模板用于真实内测执行，不是演示数据。没有发生的事件保持空白或填写“未发生”，不得为了通过阈值补填。它与设置页的“内测反馈摘要”配合使用：摘要提供反馈聚合，本文记录激活、复习闭环、留存和人工收款状态。

## 使用边界

- 每位参与者只分配一个匿名编号，例如 `P01`、`P02`；编号不要包含姓名、手机号、微信号或邮箱。
- 只记录考试方向、设备类别、版本、完成状态、匿名反馈和人工收款状态。
- 不记录题目正文、答案、API Key、聊天原文、身份证明或支付订单号。
- “已付款”只表示运营人员已经通过既有人工流程核对，不代表墨题已经接入支付系统。
- 任何付款、退款、隐私同意和外部沟通仍需遵守实际法律、平台和组织要求。

建议的内测状态说明：

- `待开始`：已同意但还未完成首次练习；
- `进行中`：已完成首次练习，仍在 7 天观察期；
- `完成`：完成 Day 7 访谈和继续使用意愿记录；
- `退出`：主动退出或连续 3 天无法联系，必须写明原因类别，不写个人隐私。

记录“完成”即可，不要复制用户作答内容。若发生阻塞，使用以下类别之一：

- `内容`：答案、解析、难度或题型问题；
- `阻塞`：无法启动、练习提交失败、错题入口不可达；
- `设备`：触控、返回键、后台恢复、断网或安装问题；
- `其他`：不属于以上类别的可复现问题。

## D. 首轮判断公式

在至少 10 个匿名编号完成登记前，结论固定为“样本不足”。达到样本数后，仍需同时取得以下结果：

| 指标 | 计算方式 | 建议阈值 |
|---|---|---:|
| 激活率 | 完成首次练习人数 / 登记人数 | ≥ 70% |
| 学习闭环完成率 | 完成练习、错题重做和到期复习人数 / 登记人数 | ≥ 40% |
| 7 日留存 | Day 7 仍主动完成学习人数 / 登记人数 | ≥ 30% |
| 付费转化 | 已付款且完成首次练习人数 / 收到邀请人数 | 单独记录，不从反馈摘要推断 |
| 继续使用意愿 | Day 7 选择“愿意”人数 / 完成访谈人数 | ≥ 50% |
| 内容投诉率 | 内容类投诉题数 / 被评价题数 | 无未处理严重答案错误 |

判定规则：

- **继续个人 Pro**：主要阈值达到，且用户明确把错题闭环视为付费理由；
- **调整定位**：使用和闭环尚可，但付款或继续意愿弱；
- **暂停商业化**：内容投诉、答案错误或留存明显失败；
- **转机构试点**：只有出现明确机构需求和至少 2 个付费试点，才重启组织、班级、报告和支付路线。
