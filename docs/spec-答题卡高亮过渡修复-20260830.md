# 墨题 Spec：修复答题卡当前题高亮过渡动效

> 试点：SDD（Spec-Driven Development）流程 —— 先写合同，再履约
> 日期：2026-08-30 | 项目：english-multiple-choice-practice-machine | 需求来源：现有 bug

## 1. 问题描述

`frontend/src/styles.css` 第 211 行：

```css
.exam-dot.current { box-shadow: 0 0 0 2px var(--primary); } transition: box-shadow .2s cubic-bezier(.22, 1, .36, 1);
```

`transition` 声明被错误地放在规则块 `}` **之外**，属于无效 CSS：
- 浏览器解析时忽略该声明（CSS 语法规则：声明必须在 `{ }` 内）
- 结果：答题卡当前题高亮（`.exam-dot.current`）从一格跳到另一格时**没有 0.2s 平滑过渡**，体验生硬

## 2. 行为规范（验收标准）

| # | 行为 | 验收方式 |
|:--|:-----|:---------|
| 1 | `.exam-dot.current` 的 `box-shadow` 高亮保留（`0 0 0 2px var(--primary)`） | 视觉检查：当前题有主色外圈 |
| 2 | 切换当前题时，高亮**平滑过渡**（~0.2s，cubic-bezier(.22,1,.36,1)） | 视觉检查：点击题号后高亮渐变而非瞬跳 |
| 3 | 不改变其他 `.exam-dot` 样式（尺寸/圆角/已答状态） | diff 检查：仅第 211 行改动 |
| 4 | CSS 语法合法 | `grep` 无 `}` 后接声明的行 |

## 3. 技术方案

将 transition 移入规则块内：

```css
.exam-dot.current { box-shadow: 0 0 0 2px var(--primary); transition: box-shadow .2s cubic-bezier(.22, 1, .36, 1); }
```

- ❌ 不动工作区其他未提交改动（vocab_plans.py / DeepExplainDrawer.vue / WrongAnalysisPanel.vue）
