# 墨题 · 英语刷题器 — 内测方案 v1.0

> 目标：用 10-20 个真实用户验证产品假设（UI 吸引力 / 功能有用性 / 留存机制），收集可执行反馈，为正式上线/闲鱼接单提供证据。

## 一、招募（目标 10-20 人）

| 渠道 | 说明 | 预期 |
|:---|:---|:---|
| **闲鱼老客** | 已有论文/PPT 客户，选学生群体（高三/大学生）| 3-5 人 |
| **B站粉丝/评论** | AI 博主定位，发一期"我用 AI 做了个刷题器"视频招募 | 5-10 人 |
| **学校/家长群** | 三年级家教客户家长 + 朋友圈 | 2-5 人 |
| **同学/校友** | 直接邀请（最可信）| 3-5 人 |

**招募话术**（简版）："我做了个免费英语刷题器（手机电脑都能用），想请几位同学帮我试用一周，反馈问题送 20 元红包/免费答疑。"

**筛选标准**：
- 正在备考（高考/考研/四级六级）——有真实刷题需求
- 每周能刷 ≥3 次
- 愿意反馈（加微信/QQ）

## 二、反馈收集机制

### 1. 内置反馈入口（建议开发）
- 设置页加"反馈建议"按钮 → 提交到后端 `feedback` 表（或直接发微信）
- 关键：**零摩擦**（3 秒内可提交，预设分类：报错/不好用/想要新功能）

### 2. 每周访谈（语音/文字）
结构化问题：
1. 这周刷了几次？每次多久？（留存信号）
2. 最喜欢哪个功能？最不常用哪个？（价值判断）
3. 有没有卡住/报错/看不懂的地方？（可用性）
4. 会推荐给同学吗？为什么？（NPS）
5. 如果收费 30 元/年，你会买吗？（付费意愿）

### 3. 埋点（建议开发，轻量）
| 事件 | 用途 |
|:---|:---|
| 练习开始/完成/放弃 | 完成率 |
| 错题查看/重做 | 错题闭环使用率 |
| 单词复习/快答 | 词汇模块粘性 |
| 报告/排行/日历访问 | 数据反馈价值 |
| 连续打卡天数 | **核心留存指标** |

> 埋点存在 `backend/data/question_bank.db` 已有 `practice_sessions`/`learning_days` 表——**先直接用已有数据**（每天会话数/打卡数），不需要新开发！

## 三、核心指标（每周看一次）

| 指标 | 目标值 | 计算 |
|:---|:---|:---|
| **周留存** | ≥40%（第 2 周还有 40% 用）| 第 2 周活跃用户 / 第 1 周 |
| **完成率** | ≥60% | 提交练习 / 创建练习 |
| **日活/周活** | ≥3 天/周 | learning_days 打卡 |
| **NPS** | ≥30 | 访谈问题 4 |
| **功能使用分布** | 练习 > 错题 > 单词 > 报告 | 埋点 |

## 四、执行计划（2 周）

| 阶段 | 时间 | 动作 |
|:---|:---|:---|
| 准备 | 第 1 周 D1-2 | 加反馈入口 + 准备测试包（5+App APK + 网页链接）|
| 招募 | 第 1 周 D3-5 | 发闲鱼/朋友圈/B站招募，拉微信群 |
| 内测期 | 第 1 周 D6 → 第 2 周 D5 | 用户使用 + 每天看后台数据 + 每 3 天访谈 1 轮 |
| 收集 | 第 2 周 D6 | 汇总反馈分类（Bug/体验/新功能）|
| 决策 | 第 2 周 D7 | 按优先级排迭代：P0 影响使用的 Bug → P1 高频吐槽 → P2 新功能 |

## 五、反馈分类模板

```
【Bug】复现步骤 + 页面 + 现象
【体验】哪个地方别扭 + 希望怎样
【新功能】想要什么 + 为什么
【惊喜】哪里超出预期（保留）
```

## 六、预算

| 项目 | 费用 |
|:---|:---|
| 测试红包（10 人 × 20 元）| 200 元 |
| 5+App 云打包 | 免费（HBuilderX）|
| 服务器/域名 | 已有本地部署，可选内网穿透（免费 frp）|

## 七、风险预案

| 风险 | 应对 |
|:---|:---|
| 用户不反馈 | 红包激励 + 每周主动私聊（不问"有没有问题"，问具体场景）|
| 用户不用 | 首日手把手带用 10 分钟 + 每日提醒打卡 |
| 数据太少 | 放宽招募：闲鱼发"刷题送真题解析" |
| 崩溃/丢数据 | 内测前备份 DB；遇问题立即修（已有千轮回归保障）|

## 八、成功标准（可验收）

- [ ] 10+ 真实用户持续使用 1 周
- [ ] 周留存 ≥40%
- [ ] 收集 ≥20 条有效反馈，P0/P1 全部修复
- [ ] 3+ 用户表示"愿意推荐/付费"
- [ ] 产出《内测报告》1 份（数据 + 反馈 + 迭代计划）
