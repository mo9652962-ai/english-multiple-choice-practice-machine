⚡ 2024 考研英语一 · 阅读 Passage 2 Q21
按键提示: A B C D Space
According to Paragraph 2, the author emphasizes that vulnerability is an inherent trait primarily because ______:
[A] it represents a permanent, irreparable structural deficiency
[B] it can only be verified through empirical cognitive scrutiny
[C] it is an intrinsic human condition rather than a temporary state
[D] it fundamentally undermines scientific consensus
🤖 墨题 AI 破题手记：
• 正解溯源 [C]：精准同义替换第 2 段末句 "inherent trait rather than an empirical fluctuation"（intrinsic 替换 inherent，human condition 替换 trait）。
• 避坑排查 [A]：偷换概念，文章未提及 "irreparable"（不可逆转）。敲击 Space 可再次收起本面板。
